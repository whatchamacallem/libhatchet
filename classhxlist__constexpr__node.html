Detailed Description

hxlist_constexpr_node - Intrusive doubly linked list node base.

This is the same as hxlist except that it works with constexpr at the expense of using an additional pointer per-node. Derive from hxlist_constexpr_node to make a type linkable into an hxlist_constexpr. Copy construction produces an unlinked node and assignment does nothing.
