Detailed Description

template<typename T, hxsize_t fixed_capacity_, bool pow2_ = false>
class hxallocator< T, fixed_capacity_, pow2_ >

hxallocator<1+> - Provides static allocation when capacity is greater than zero.

When pow2_ is true, fixed_capacity_ is interpreted as 1 << fixed_capacity_ along with all other references to capacity.
