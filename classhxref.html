Detailed Description

template<typename T>
class hxref< T >

hxref<T> - Holds a reference to a value of type T, or null.

Implements the non-owning pointer std::optional<T&>. A null reference compares equal to hxnil. Assignment rebinds the reference instead of assigning through to the referent, matching pointer semantics. Use hxref<const T> where write through should be prevented.

  • T : The referenced value type. Must not be an array, reference or pointer type.
