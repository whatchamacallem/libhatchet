Detailed Description

hxconstexpr_list_node - Intrusive doubly linked list node base.

This is the same as hxlist except that it works with constexpr at the expense of using an additional pointer per-node. Derive from hxconstexpr_list_node to make a type linkable into an hxconstexpr_list. Copy construction produces an unlinked node and assignment does nothing.
