Detailed Description

User-specializable key-equal, key-less, key-hash, and key-three-way callables.

Override key operations for a type by explicitly specializing hxkey_equal_t, hxkey_less_t, hxkey_three_way_t, or hxkey_hash_t, the same way std::hash is specialized. Specializations are evaluated when and where the derived container is instantiated and must be consistently available.
