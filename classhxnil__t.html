Detailed Description

hxnil_t - A class that will only convert to a null T pointer or a null hxhandle_t.

Useful when an integer literal 0 arg would be ambiguous or otherwise break template code. Also used as a tag for nothing. Use plain hxnull for == and != comparisons.
