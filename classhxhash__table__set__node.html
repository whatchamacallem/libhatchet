Detailed Description

template<typename key_t_>
class hxhash_table_set_node< key_t_ >

hxhash_table_set_node - Optional base class for unordered set entries.

Caches the hash value. See hxhash_table_map_node if you need a map node. Copying and assignment are unimplemented and the key must be immutable in any assignment operation in a subclass.
