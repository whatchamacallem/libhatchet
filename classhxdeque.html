Detailed Description

template<hxdeque_concept_ T, hxsize_t capacity_ = hxallocator_dynamic_capacity>
class hxdeque< T, capacity_ >

hxdeque - A fixed-capacity deque backed by a power-of-two ring buffer.

All operations are O(1). The effective capacity must be a power of two and positive once storage is allocated. This is designed to do one thing very well and that is all.

  • T : The element type stored in the deque.
  • capacity : Maximum element count or hxallocator_dynamic_capacity for dynamic storage.
